# Oxide website

Voice lab notebook for researchers — https://anasbq.github.io/Oxide.github.io/

- `index.html` — home page, drawn from `content.json`
- `page.html?p=<slug>` — extra pages (also in `content.json`, written in Markdown)
- `admin/` — control panel: edit the home page, add/remove sections, cards and pages, contact and footer. Saving commits `content.json` with a fine-grained GitHub token (Contents: Read and write on this repository) that stays in your browser.
- `assets/` — shared styles and the renderer
